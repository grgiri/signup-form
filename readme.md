# Odin Sign-Up Form

A sign-up form project built as part of [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form) Intermediate HTML and CSS curriculum.

## About

This project focuses on building a real-world style sign-up form from a provided design mockup. The goal was to practice HTML form elements, CSS layout techniques, and interactive input styling using pseudo-classes.

## Features

- Two-column page layout using **Flexbox**
- Two-column form grid using **CSS Grid**
- Background image sidebar with a semi-transparent logo overlay
- Input focus state with a **blue border and box-shadow**
- Invalid password inputs highlighted with a **red border**
- Clean card-style form section with subtle box-shadow
- Fully styled submit button and login link

## Built With

- HTML5
- CSS3 (Flexbox, Grid, Pseudo-classes)

## Concepts Practiced

- Semantic HTML form elements (`input`, `label`, `button`)
- CSS Flexbox for page-level layout
- CSS Grid for the two-column form field layout
- `:focus` pseudo-class for active input styling
- `:invalid` pseudo-class for password validation feedback
- `:not(:placeholder-shown):invalid` pattern to avoid showing errors on page load
- `background-image`, `background-size`, and `background-position` for the sidebar
- Semi-transparent overlays using `rgba()`
